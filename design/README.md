# Design source

The Claude Design handoff this app was built from, kept here so the intent stays
next to the implementation.

- `Bedtime Player Prototype.dc.html` - the design that was built. Read this one.
- `Bedtime Player.dc.html` - the earlier exploration canvas with three
  directions per screen. Kept for context; the prototype is the decision.
- `ios-frame.jsx` - the mock device bezel the prototype renders inside. Not part
  of the app: on the phone the real status bar and home indicator do that job.
- `support.js` - the Claude Design runtime the prototypes need to render. Not
  used by the app.

These are prototypes, not production code. `README.md` in the repository root
lists where the implementation deliberately departs from them.
